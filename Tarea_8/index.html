Tarea 8: Introduccion a CSS

Tipos de estilos en CSS

Estilos en Linea.

Estos estilos se van a agregar directamente en ele elemento html, mediante el atributo "style".

Este parrafo tiene estilo en linea.

Estilos Internos.

Estos estilos se agregan en el mismo archivo html dentro de la etiqueta <head> y para agregarlos se utiliza el elemento <style>.

Estilos Externos.

Estos estilos son los que se recomienda utilizar, ya que ofrecen modularidad, fácil mantenimiento, orden, eficiencia, entre otras evntajas. Para agregar una hoja de estilos externa, dentro de la etiqueta <head> se utiliza el elemento <link>, donde se especifíca la ruta de nuestra hoja de estilos.
