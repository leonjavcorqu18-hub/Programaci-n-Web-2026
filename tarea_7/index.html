Resumen HTML: Principales conceptos y etiquetas

Esta página va a resumir los principales conceptos y etiquetas vistas en la clase de programación web 1, en el módulo de HTML.

Conceptos principales de HTML

HTML

El lenguaje de marcado de hipertexto es un lenguaje de marcas que se utiliza para estructuras sitios web.

Elemento HTML

Un elemento HTML es la unidad básica de estructura y contenido en una página web, y está compuesta de:

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <head>

Es una etiqueta que se utiliza para comunicarse con el navegador a través de los metadatos, permite mejorar el SEO, además se enlazan archivos externos de estilos o scripts.

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra página web.

Contenedores semánticos

<header> Es una etiqueta utilizada para el contenido introductorio de una página web, puede contener el logo, el menú de navegación principal, el nombre de la empresa, etc.
<nav> Etiqueta utilizada para el menú de la navegación principal, suele contener enlaces a otras páginas relacionadas o navegar por la página principal, no debe haber más de una página.
<main> Etiqueta unica de una página web cuyo objetivo es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocará el contenido principal de nuestra página.
<section> Es una etiqueta que poco a poco se intenta que sustituya a <div>, su uso es para dividir a una página web en secciones y agrupar contenido relacionado
<article> Es una etiqueta que se utiliza para agrupar contenido autónomo que si se separa de otyro contenido, sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<footer> Es una etiqueta que normalmente se encuentra hasta el final de una página y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria.
<aside> Esta etiqueta representa una sección de la página web cuyo contenido no está relacionado con el contenido principal del documento, como: barras laterales, publicidad. enlaces a otros artículos relacionados, etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar a otras páginas:

  • Externos
  • Internos
  • Ancla/De anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/5542649521"
Este valor envia un mensaje de WhatsApp a un número específicado.
href="mailto:example@gmail.com"
Este valor envía un correo a un mail específico.

Elemento <form>

Es la forma en que los usuarios de un sitio web pueden comunicarse con el, mediante el formulario se reciben, procesan y envián datos de los usuarios para el fin u objetivo del sitio web
